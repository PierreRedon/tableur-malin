Insérer la date du jour en deux touches avec Ctrl + ;

Fonctionne dans Excel, Google Sheets. Niveau débutant.

Cliquez dans la cellule, puis appuyez sur Ctrl + ; (la touche Ctrl et le point-virgule) : la date du jour s'inscrit. Validez avec Entrée. Cette date reste fixe : elle ne changera pas demain.

Les étapes

  1. Cliquez dans la cellule où la date doit apparaître.
  2. Maintenez la touche Ctrl enfoncée et appuyez sur la touche ; (point-virgule). La date du jour s'inscrit dans la cellule.
  3. Validez avec Entrée.

À savoir

Le raccourci inscrit une date fixe, exactement comme si vous l'aviez tapée à la main. C'est ce qu'il faut pour noter le jour d'une réception, d'un paiement, d'un appel ou d'une relance : la date ne doit plus bouger ensuite.

La formule =AUJOURDHUI() fait l'inverse : elle est recalculée à chaque ouverture du fichier et affiche toujours la date du moment. Elle est utile pour calculer un nombre de jours restants ou un retard, mais pas pour garder la trace d'un événement.

Pour l'heure, le raccourci indiqué par Microsoft est Ctrl + Maj + ; (point-virgule). Sur un clavier français, essayez aussi Ctrl + : (deux-points). Pour obtenir la date et l'heure dans la même cellule, insérez la date, tapez une espace, puis insérez l'heure.

Dans Google Sheets

Le raccourci est le même dans Google Sheets : Ctrl + ; pour la date du jour (⌘ + ; sur Mac) et Ctrl + Maj + ; pour l'heure. La formule =AUJOURDHUI() existe aussi, avec le même comportement : elle change chaque jour.

Les pièges à éviter

  • Ne confondez pas avec =AUJOURDHUI() : une date saisie avec cette formule aura changé demain. Pour dater un événement, utilisez le raccourci.
  • Si la cellule affiche un nombre comme 46340 au lieu d'une date, elle est au format Nombre. Dans Excel, faites un clic droit, choisissez Format de cellule, puis la catégorie Date.
  • Le raccourci agit sur la cellule sélectionnée ou en cours de saisie. Si rien ne se passe, vérifiez que vous n'êtes pas dans une autre fenêtre ou dans une zone de recherche.
  • Sur Mac, le raccourci d'Excel peut différer selon la version : essayez Contrôle + ; (point-virgule).
