Créer une liste déroulante dans une cellule

Fonctionne dans Excel, Google Sheets. Niveau débutant.

Dans Excel : onglet Données, Validation des données, Autoriser « Liste ». Dans Google Sheets : menu Insertion, Menu déroulant.

Les étapes dans Excel

  1. Sélectionnez les cellules qui doivent proposer la liste.
  2. Dans Excel, ouvrez l'onglet Données puis cliquez sur Validation des données.
  3. Dans le champ Autoriser, choisissez Liste.
  4. Dans le champ Source, tapez vos choix séparés par des points-virgules, ou sélectionnez une plage qui les contient.
  5. Validez : une flèche apparaît à droite de la cellule quand vous cliquez dessus.

À savoir

Si la liste risque d'évoluer, écrivez plutôt vos choix dans une colonne à part, sur un autre onglet par exemple, et indiquez cette plage comme source. Vous n'aurez qu'à modifier la colonne pour mettre à jour toutes les listes.

Dans Google Sheets

Dans Google Sheets, sélectionnez les cellules puis ouvrez le menu Insertion et choisissez Menu déroulant. Saisissez chaque choix dans le panneau qui s'ouvre à droite ; vous pouvez attribuer une couleur à chacun.

Les pièges à éviter

  • Une liste déroulante n'empêche pas de coller une autre valeur par-dessus : le collage remplace aussi la règle de validation.
  • Dans Excel en français, le séparateur des choix est le point-virgule, pas la virgule.
