Afficher toutes les formules d'une feuille Excel avec Ctrl + "

Fonctionne dans Excel, Google Sheets. Niveau débutant.

Sur un clavier français, appuyez sur Ctrl + " (la touche du 3, en haut du clavier) : chaque cellule montre sa formule au lieu de son résultat. Appuyez une seconde fois pour revenir aux résultats. Le bouton Afficher les formules de l'onglet Formules fait la même chose.

Les étapes dans Excel

  1. Ouvrez la feuille dont vous voulez voir les formules.
  2. Maintenez Ctrl et appuyez sur la touche ", celle du chiffre 3 dans la rangée du haut (sans la touche Maj).
  3. Toutes les cellules qui contiennent une formule affichent cette formule ; les colonnes s'élargissent pour laisser la place.
  4. Repérez ce qui cloche : une cellule qui montre un nombre au milieu d'une colonne de formules a été tapée à la main.
  5. Appuyez de nouveau sur Ctrl + " pour revenir aux résultats.
  6. Si le raccourci ne répond pas, ouvrez l'onglet Formules et cliquez sur le bouton Afficher les formules ; cliquez dessus une seconde fois pour revenir.

À savoir

D'habitude, une cellule montre le résultat, et la formule n'apparaît que dans la barre de formule, une cellule à la fois. Pour comprendre un fichier reçu d'un collègue, ou vérifier le vôtre, il faudrait cliquer sur chaque cellule. L'affichage des formules les montre toutes en même temps, directement dans la grille.

Quelle touche, exactement ? L'aide de Microsoft indique le raccourci Ctrl + ` (l'accent grave), qui correspond aux claviers américains. Sur un clavier français, c'est Ctrl + " : la touche qui porte le 3 et les guillemets, dans la rangée du haut. Si rien ne se passe sur votre clavier, passez par le ruban : onglet Formules, bouton Afficher les formules. Il se trouve dans le groupe qui s'appelle, selon les versions, « Audit de formules » ou « Vérification des formules ».

À quoi ça sert ? À repérer d'un coup d'œil la cellule où quelqu'un a tapé un nombre par-dessus une formule, à vérifier qu'une formule a bien été recopiée jusqu'en bas, ou à voir quelles cellules sont des calculs avant de modifier un tableau que vous ne connaissez pas.

Les colonnes s'élargissent, c'est normal. L'aide de Microsoft le précise : les colonnes s'élargissent automatiquement pour afficher les formules, et elles reprennent leur taille quand vous revenez à l'affichage normal. Pendant ce temps, les nombres et les dates perdent aussi leur mise en forme à l'écran ; rien n'est modifié dans le fichier.

Une feuille à la fois. Le réglage ne concerne que la feuille affichée. Pour un autre onglet, refaites le raccourci dans cet onglet.

Garder une formule visible à côté de son résultat. Pour montrer une seule formule, dans un mode d'emploi par exemple, la fonction FORMULETEXTE écrit dans une cellule la formule d'une autre : =FORMULETEXTE(B2).

Dans Google Sheets

Dans Google Sheets, ouvrez le menu Affichage, puis Afficher, puis Formules ; refaites le même chemin pour revenir aux résultats. La liste officielle des raccourcis de Google mentionne bien « Afficher toutes les formules » (Ctrl + ~), mais prévient que certains raccourcis ne fonctionnent pas avec tous les claviers : sur un clavier français, le menu est le plus sûr.

Les pièges à éviter

  • Si vous imprimez pendant que les formules sont affichées, ce sont les formules qui sortent sur le papier. Revenez aux résultats avant d'imprimer.
  • Vous avez appuyé sur Ctrl + " par mégarde et toute la feuille montre des formules ? Rien n'est cassé : refaites le raccourci, ou cliquez sur Afficher les formules dans l'onglet Formules.
  • Si une seule cellule montre sa formule au lieu du résultat, ce n'est pas ce réglage : la cellule est sans doute au format Texte. Donnez-lui le format Standard, puis appuyez sur F2 et sur Entrée.
  • Sur un ordinateur portable ou un clavier d'une autre langue, la touche peut être différente. Le bouton du ruban fonctionne dans tous les cas.
  • Sur Mac, plusieurs guides indiquent Contrôle + ` (accent grave). Si le raccourci ne répond pas, utilisez le bouton Afficher les formules de l'onglet Formules.
