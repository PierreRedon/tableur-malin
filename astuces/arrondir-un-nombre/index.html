Arrondir un nombre dans Excel

Fonctionne dans Excel, Google Sheets. Niveau débutant.

Tapez =ARRONDI(A2;2) pour arrondir le nombre de la cellule A2 à deux décimales : 1234,567 devient 1234,57. Remplacez le 2 par 0 pour obtenir un nombre entier.

Les étapes

  1. Cliquez dans une cellule vide, à côté du nombre à arrondir.
  2. Tapez =ARRONDI(A2;2) : A2 est la cellule qui contient le nombre, et 2 le nombre de décimales à garder.
  3. Validez avec Entrée. Si A2 contient 1234,567, la cellule affiche 1234,57.

À savoir

Il y a deux façons très différentes de faire disparaître des décimales. Les boutons de décimales de l'onglet Accueil (ajouter ou réduire) changent seulement l'affichage : la cellule montre 1234,57, mais Excel continue de calculer avec 1234,567. La fonction ARRONDI, elle, change réellement la valeur.

C'est ce qui explique les totaux qui semblent faux de quelques centimes : les lignes affichées sont arrondies à l'écran, mais l'addition porte sur les valeurs complètes. Pour qu'un total corresponde à ce qui est affiché, par exemple sur une facture, arrondissez chaque ligne avec ARRONDI avant d'additionner.

Vous pouvez arrondir directement le résultat d'un calcul en le plaçant dans la fonction : =ARRONDI(B2*C2;2) arrondit le produit de B2 par C2 à deux décimales.

Dans Google Sheets

Les fonctions portent les mêmes noms dans Google Sheets en français : ARRONDI, ARRONDI.SUP et ARRONDI.INF, avec le point-virgule entre les deux éléments. La distinction est la même : les boutons de décimales de la barre d'outils ne changent que l'affichage.

Les pièges à éviter

  • Réduire les décimales affichées n'arrondit pas la valeur : les calculs suivants utilisent toujours le nombre complet.
  • Séparez les deux éléments par un point-virgule, et écrivez les décimales avec une virgule : =ARRONDI(12,345;2).
  • ARRONDI.SUP éloigne de zéro et ARRONDI.INF rapproche de zéro : avec un nombre négatif, =ARRONDI.SUP(-3,2;0) donne -4.
  • N'arrondissez pas trop tôt dans une suite de calculs : gardez les valeurs complètes dans les étapes intermédiaires et arrondissez le résultat final, sauf quand chaque ligne doit correspondre à un montant réellement facturé.
