Aller à la ligne dans une cellule

Fonctionne dans Excel, Google Sheets. Niveau débutant.

Pendant que vous écrivez dans la cellule, appuyez sur Alt + Entrée à l'endroit où le texte doit passer à la ligne. Dans Google Sheets, le raccourci est Ctrl + Entrée.

Les étapes dans Excel

  1. Double-cliquez dans la cellule (ou sélectionnez-la et appuyez sur F2) pour modifier son contenu.
  2. Placez le curseur à l'endroit exact où le texte doit être coupé.
  3. Appuyez sur Alt + Entrée : la suite du texte passe à la ligne, dans la même cellule.
  4. Validez avec Entrée. La hauteur de la ligne s'adapte pour afficher tout le texte.

À savoir

Si vous voulez seulement qu'un texte trop long reste dans sa colonne, sans choisir vous-même où il est coupé, sélectionnez les cellules et cliquez sur le bouton Renvoyer à la ligne automatiquement, dans l'onglet Accueil, groupe Alignement. Le texte se replie alors selon la largeur de la colonne, et s'ajuste si vous l'élargissez.

Les deux méthodes se complètent : Alt + Entrée impose une coupure à un endroit précis (une adresse sur deux lignes, par exemple), le renvoi automatique s'occupe du reste.

Dans Google Sheets

Dans Google Sheets, appuyez sur Ctrl + Entrée pendant la saisie (⌘ + Entrée sur Mac). Sous Windows, Alt + Entrée fonctionne aussi. Pour le renvoi automatique, sélectionnez les cellules puis ouvrez le menu Format et choisissez l'option de retour à la ligne automatique qui renvoie le texte à la ligne.

Les pièges à éviter

  • Appuyer sur Entrée seule ne crée pas de nouvelle ligne : cela valide la cellule et passe à la suivante.
  • Si une partie du texte reste cachée, la hauteur de la ligne a sans doute été fixée à la main. Dans Excel, onglet Accueil, bouton Format, choisissez Ajuster la hauteur de ligne.
  • Alt + Entrée est le raccourci d'Excel pour Windows. Sur Mac, la combinaison dépend de la version : essayez Option + Retour, ou Contrôle + Option + Retour.
