Supprimer les doublons d'une liste en deux clics

Fonctionne dans Excel, Google Sheets. Niveau débutant.

Dans Excel : onglet Données, Supprimer les doublons. Dans Google Sheets : menu Données, Nettoyage des données, Supprimer les doublons.

Les étapes dans Excel

  1. Faites une copie de votre onglet : la suppression est définitive une fois le fichier enregistré.
  2. Cliquez dans votre tableau.
  3. Dans Excel, ouvrez l'onglet Données et cliquez sur Supprimer les doublons.
  4. Cochez « Mes données ont des en-têtes » si la première ligne contient des titres, puis choisissez les colonnes à comparer.
  5. Validez. Excel indique combien de lignes ont été supprimées et combien il en reste.

À savoir

Le choix des colonnes compte. Si vous cochez seulement la colonne E-mail, deux lignes avec le même e-mail sont des doublons, même si le reste diffère. Si vous cochez toutes les colonnes, seules les lignes entièrement identiques sont supprimées. Dans tous les cas, c'est la première ligne rencontrée qui est conservée.

La fonction UNIQUE est disponible dans Excel 2021, Microsoft 365 et Google Sheets. Elle se met à jour quand la liste d'origine change.

Dans Google Sheets

Dans Google Sheets, sélectionnez la plage, ouvrez le menu Données, puis Nettoyage des données, et choisissez Supprimer les doublons.

Les pièges à éviter

  • « Dupont » et « Dupont » suivi d'un espace ne sont pas des doublons pour le tableur. Nettoyez d'abord les espaces avec la fonction SUPPRESPACE.
