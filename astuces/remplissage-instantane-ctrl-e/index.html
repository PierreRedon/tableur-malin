Séparer prénom et nom sans formule avec Ctrl + E

Fonctionne dans Excel. Niveau débutant.

Tapez le résultat attendu pour la première ligne, validez, puis appuyez sur Ctrl + E : Excel comprend le modèle et remplit toute la colonne.

Les étapes

  1. Placez-vous dans la colonne juste à droite de vos données. Si vos noms complets sont en colonne A, travaillez en colonne B.
  2. En B2, tapez à la main le résultat voulu pour la première ligne, par exemple le prénom « Camille », puis validez avec Entrée.
  3. Appuyez sur Ctrl + E. Excel remplit toutes les lignes en suivant votre exemple.
  4. Recommencez en colonne C avec le nom de famille.

À savoir

Le remplissage instantané ne sert pas qu'aux prénoms. Il fonctionne dès qu'un modèle se répète : extraire le code postal d'une adresse, mettre des numéros de téléphone au même format, assembler prénom et nom dans une seule cellule, passer une colonne en majuscules.

Le raccourci se retrouve aussi dans le menu Données, bouton Remplissage instantané. Il existe depuis Excel 2013.

Dans Google Sheets

Google Sheets n'a pas de raccourci Ctrl + E. Pour séparer un prénom et un nom, utilisez la fonction SPLIT, qui coupe le texte à chaque espace et range les morceaux dans les cellules voisines.

Les pièges à éviter

  • Le résultat est figé : si vous corrigez un nom en colonne A, la colonne B ne suit pas. Refaites Ctrl + E, ou passez par une formule.
  • Si Excel se trompe sur une ligne (prénom composé, particule), corrigez deux ou trois exemples à la main et relancez Ctrl + E.
  • Aucune colonne vide ne doit séparer vos données de la colonne à remplir.
