Transformer une liste en tableau avec Ctrl + T

Fonctionne dans Excel, Google Sheets. Niveau débutant.

Cliquez dans n'importe quelle cellule de votre liste, appuyez sur Ctrl + T, puis validez avec Entrée : la liste devient un tableau, avec des boutons de filtre sur les titres et une ligne sur deux colorée.

Les étapes dans Excel

  1. Cliquez dans n'importe quelle cellule de votre liste. Inutile de tout sélectionner.
  2. Maintenez Ctrl et appuyez sur T. La boîte « Créer un tableau » s'ouvre et propose la plage qu'Excel a repérée, par exemple =$A$1:$C$7.
  3. Vérifiez que la plage couvre bien toute votre liste. Si la première ligne contient vos titres de colonnes, laissez cochée la case « Mon tableau comporte des en-têtes ».
  4. Validez avec Entrée ou cliquez sur OK : les titres reçoivent un bouton de filtre et les lignes alternent deux couleurs.
  5. Sans le clavier, le même résultat s'obtient par l'onglet Insertion, bouton Tableau, ou par l'onglet Accueil, bouton « Mettre sous forme de tableau », qui laisse choisir les couleurs.

À savoir

Une liste et un tableau se ressemblent, mais Excel ne les traite pas de la même façon. Une fois la liste transformée en tableau, plusieurs choses se font toutes seules :

  • chaque titre de colonne porte un bouton pour trier et filtrer ;
  • une ligne sur deux est colorée (les « lignes à bandes »), ce qui facilite la lecture ;
  • le tableau s'agrandit de lui-même quand vous tapez une nouvelle ligne juste en dessous, et celle-ci prend la même mise en forme ;
  • une formule tapée dans une colonne se recopie sur toutes les lignes (les « colonnes calculées ») ;
  • une ligne des totaux peut être affichée en bas du tableau, depuis l'onglet « Création de tableau ».

Cet onglet « Création de tableau » apparaît dans le ruban dès que vous cliquez dans le tableau (il peut s'appeler simplement « Tableau » selon la version). C'est là que l'on change les couleurs et que l'on active ou non les lignes à bandes.

Pour revenir en arrière, cliquez dans le tableau, puis sur « Convertir en plage » dans ce même onglet : les données restent en place, mais redeviennent une liste ordinaire.

Si vous cherchez seulement les boutons de filtre, sans changer l'apparence de la liste, Ctrl + Maj + L suffit.

Dans Google Sheets

Google Sheets propose aussi des tableaux, depuis 2024. Cliquez dans votre liste, ouvrez le menu Format, puis choisissez « Convertir en tableau ». Le raccourci clavier indiqué pour Windows est Ctrl + Alt + T. Comme dans Excel, les titres reçoivent un menu de filtre et les lignes alternent deux couleurs.

Les pièges à éviter

  • Une ligne entièrement vide au milieu de la liste arrête la détection : Excel ne propose alors que la partie située au-dessus ou au-dessous. Regardez toujours la plage affichée dans la boîte « Créer un tableau » avant de valider.
  • Si votre liste n'a pas de ligne de titres, décochez « Mon tableau comporte des en-têtes » : Excel ajoute alors des titres provisoires (Colonne1, Colonne2, etc.) que vous pouvez renommer.
  • Dans Excel, Ctrl + T crée un tableau ; dans Google Sheets, le raccourci est différent (Ctrl + Alt + T).
  • Les couleurs ne vous plaisent pas ? Inutile de tout refaire : choisissez un autre style dans l'onglet « Création de tableau ».
