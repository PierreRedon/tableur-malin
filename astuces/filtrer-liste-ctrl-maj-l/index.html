Filtrer une liste en trois touches avec Ctrl + Maj + L

Fonctionne dans Excel, Google Sheets. Niveau débutant.

Cliquez dans votre liste, puis appuyez sur Ctrl + Maj + L : une petite flèche apparaît à côté de chaque titre de colonne. Cliquez sur une flèche, cochez ce que vous voulez voir, validez. Les autres lignes sont masquées, pas supprimées.

Les étapes

  1. Cliquez sur n'importe quelle cellule de votre liste. La première ligne doit contenir les titres des colonnes.
  2. Maintenez Ctrl et Maj enfoncées, puis appuyez sur L : une flèche apparaît dans chaque cellule de titre.
  3. Cliquez sur la flèche de la colonne à filtrer, par exemple Ville.
  4. Décochez (Sélectionner tout), cochez la ou les valeurs à garder, par exemple Lyon, puis cliquez sur OK.
  5. Pour tout réafficher, appuyez de nouveau sur Ctrl + Maj + L : les flèches disparaissent et toutes les lignes reviennent.

À savoir

Un filtre ne supprime rien : il masque provisoirement les lignes qui ne vous intéressent pas. C'est le moyen le plus simple de retrouver les clients d'une ville, les factures d'un mois ou les lignes encore vides dans une longue liste.

Le raccourci fait la même chose que le bouton Filtrer de l'onglet Données. Dans Excel, vous reconnaissez une liste filtrée à deux détails : les numéros des lignes passent en bleu, et la flèche de la colonne concernée est remplacée par un petit entonnoir.

Vous pouvez filtrer plusieurs colonnes à la suite, par exemple la ville puis le mois : seules les lignes qui respectent toutes les conditions restent affichées. Sur une colonne de nombres, le menu de la flèche propose aussi des filtres numériques, pour ne garder que les montants supérieurs à une valeur. Pour retirer le filtre d'une seule colonne sans toucher aux autres, cliquez sur son entonnoir, puis sur la commande Effacer le filtre.

Le petit total affiché en bas de la fenêtre suit le filtre : voyez la somme sans formule.

Dans Google Sheets

Dans Google Sheets, cliquez dans la liste, ouvrez le menu Données, puis choisissez Créer un filtre. Sur PC, le raccourci Ctrl + Maj + L fait la même chose. Une icône de filtre apparaît dans chaque titre : cliquez dessus, décochez les valeurs à masquer, puis validez avec OK. La fonction SOUS.TOTAL existe aussi, avec la même écriture.

Les pièges à éviter

  • Une ligne entièrement vide au milieu de la liste arrête le filtre : les lignes situées en dessous ne sont pas prises en compte. Supprimez la ligne vide, ou sélectionnez toute la liste avant d'utiliser le raccourci.
  • Sans ligne de titres, c'est votre première ligne de données qui reçoit les flèches et qui n'est plus filtrée. Ajoutez toujours une ligne de titres.
  • Les lignes masquées existent toujours : une formule SOMME continue de les additionner. Pour un total qui suit le filtre, utilisez SOUS.TOTAL.
  • Le raccourci fonctionne comme un interrupteur : si les flèches sont déjà là, il les retire et annule vos filtres en cours.
  • Sur Mac, le raccourci d'Excel peut différer selon la version : essayez ⌘ + Maj + F, ou passez par l'onglet Données, bouton Filtrer.
