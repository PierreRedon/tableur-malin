Additionner une colonne en deux touches avec Alt + =

Fonctionne dans Excel. Niveau débutant.

Cliquez dans la cellule située juste sous vos nombres, appuyez sur Alt + =, puis validez avec Entrée : Excel écrit la formule SOMME et choisit lui-même la plage à additionner.

Les étapes

  1. Cliquez dans la cellule vide située juste sous la colonne de nombres à additionner, par exemple B7 si vos montants vont de B2 à B6.
  2. Appuyez sur Alt + =. Excel écrit la formule SOMME et entoure la plage qu'il propose d'additionner.
  3. Vérifiez que la plage proposée est la bonne, puis validez avec Entrée.
  4. Pour plusieurs totaux d'un coup, sélectionnez d'abord toutes les cellules de total (par exemple B7 à D7), puis appuyez sur Alt + = : chaque colonne reçoit sa somme, sans passer par Entrée.

À savoir

Ce raccourci déclenche le bouton Somme automatique, que l'on trouve aussi dans l'onglet Accueil et dans l'onglet Formules. Il fonctionne également pour une ligne : placez-vous dans la cellule située à droite des nombres.

Le total reste une formule ordinaire : si vous modifiez un montant, il se recalcule tout seul.

Dans Google Sheets

Dans Google Sheets, le plus sûr est de taper la formule ci-dessous dans la cellule du total. Vous pouvez aussi sélectionner vos nombres, cliquer sur le bouton Fonctions (Σ) de la barre d'outils et choisir SOMME.

Les pièges à éviter

  • Excel s'arrête à la première cellule vide : si votre colonne contient un trou, la plage proposée est incomplète. Corrigez-la avant de valider.
  • Un nombre saisi comme du texte (souvent aligné à gauche dans la cellule) n'est pas compté dans la somme.
  • Le raccourci Alt + = est celui d'Excel pour Windows. Sur Mac, le plus simple est de cliquer sur le bouton Somme automatique de l'onglet Accueil.
